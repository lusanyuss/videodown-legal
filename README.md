# Video Downloader public documents

Static bilingual legal and support pages plus a developer-generated download review fixture. Owned by lusanyuss; no app source, signing material, SDKs, user media or credentials are published here.

Build and check: `python -X utf8 build.py`.

Provider: lu sanyu. Contact: lusanyuss@gmail.com.

`review/` contains the existing six-second, 1280x720 synthetic H.264 test pattern. The exact media fingerprint and generation record are in `review/provenance.json`; the build checks them before publishing. Download permission applies only to this fixture. The page uses no scripts, forms or tracking SDKs.
